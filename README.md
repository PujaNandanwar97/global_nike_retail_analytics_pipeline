# Nike Global Retail Analytics Pipeline

## Project Overview
This project is a Big Data Retail Analytics Pipeline built using PySpark and Databricks.

The dataset contains Nike product catalog data from 45 countries with more than 1.4 million records.  
The project focuses on data engineering, transformation, KPI generation, Delta Lake storage, and advanced retail analytics.

# Project Workflow

## Data Ingestion
- Uploaded multiple CSV files into Databricks
- Combined and processed large-scale retail data

## Exploratory Data Analysis (EDA)
- Product distribution analysis
- Category analysis
- Country-wise product insights
- Pricing analysis

## Data Transformation
- Cleaned null values
- Converted data types
- Processed pricing columns
- Generated transformed datasets

## Delta Lake Integration
- Stored cleaned data as Delta Tables
- Read Delta tables for optimized analytics

## Advanced Business KPI Analysis
- Average price by country
- Product availability analysis
- Gender segment analysis
- Most common categories
- Top expensive products
- Size distribution analysis

## Window Functions
Used PySpark Window Functions to rank top expensive products country-wise.
